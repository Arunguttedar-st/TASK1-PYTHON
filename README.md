# Sum, Average, Maximum and Minimum Calculatoion

## Description
This is a simple Python program. It takes numbers from the user and finds the sum, average, maximum, and minimum of those numbers.

## How to Use
1. Run the Python program.
2. Enter numbers separated by spaces.
3. The program will display the sum, average, maximum, and minimum values.

## Example

Input:
10 20 30 40 50

Output:
Sum: 150
Average: 30.0
Maximum: 50
Minimum: 10
