# Number Statistics Calculator

A simple Python program that calculates the sum, average, maximum, and minimum values from user-input numbers.

## Features

- Takes multiple numbers as space-separated input.
- Automatically calculates:
  - **Sum** of all numbers
  - **Average** (mean)
  - **Maximum** value
  - **Minimum** value

## How to Run

1. Open your terminal in the project directory.
2. Run the script:
   ```bash
   python task.py
